# REDFILM AI Pick + Watch PWA Install

## Реализовано

- Публичное название REDFILM Match заменено на «ИИ-подбор», URL `/match` сохранён.
- Пользователь может описать интерес текстом или выбрать быстрый сценарий.
- Локальный recommendation engine формирует кандидатов, OpenAI ранжирует только существующие Movie ID.
- Structured Outputs, серверная валидация, timeout, дневной бюджет, rate limit и локальный fallback.
- Учёт токенов, оценочной стоимости, режима AI/fallback и анонимного session hash.
- Админка `/admin/ai-pick`: включение, модель, бюджет, размер пула, статистика и последние запросы.
- PWA provider и service worker без агрессивного кэширования.
- На `/watch/[slug]` после похожих размещён блок «Установите REDFILM — Быстрый доступ к фильмам и сериалам».
- Android вызывает системный install prompt; iOS показывает инструкцию «Поделиться → На экран Домой».
- Блок скрывается в standalone и Telegram Mini App.

## Миграция

`20260731110000_add_ai_match_control` добавляет `AiMatchUsage` и `AiMatchConfig`.

## Обязательная переменная

`OPENAI_API_KEY` уже используется проектом. Ключ не передаётся клиенту.

## Проверка после деплоя

1. `/match`: ввести пожелание и получить режим «ИИ-ранжирование».
2. `/admin/ai-pick`: проверить запись токенов и стоимости.
3. `/watch/<slug>` на Android/iOS: проверить install card.
4. Отключить AI в админке и убедиться, что подбор работает в `LOCAL_FALLBACK`.
